# 9.7.2 GetMagicBoxNum

Description: 获取MagicBox的设备数量 

KeyWords:

portName: string

device: hex(lite:0x02, Go:0x04, K210car:0x20, K210arm:0x21)



INPUT:

```json

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicianGO.GetMagicBoxNum",
    "params": {
        "portName": "COM4" 
    }
}
```
