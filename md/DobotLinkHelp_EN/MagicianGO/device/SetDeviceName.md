# 9.3.3 SetDeviceName

Description: 设置设备名称

KeyWords:

portName: string

deviceName: string



INPUT:

```json

{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicianGO.SetDeviceName",
    "params": {
        "portName": "COM4",
        "deviceName": "MgoNO.1"
    }
}
```
