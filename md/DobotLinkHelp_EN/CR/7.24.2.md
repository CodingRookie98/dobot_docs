# 7.24.2 GetCRRunTo

功能:

 协作运动接口,用于获取当前的运动状态 



INPUT:

```json

```json

{
    "id": 1,
    "jsonrpc": "2.0",
     "method": "dobotlink.CR.GetCRRunTo",
      "params": {
        "portName": "192.168.5.1"     }
}

```



OUTPUT：

```json

```json
{    "id": 1,
    "jsonrpc": "2.0",
    "result": {
        "value":true,   // bool 量  到达位置为true,运动中为false
         "isAlarms":true // bool 量  发生报警为true 正常为 false
       }}
```
