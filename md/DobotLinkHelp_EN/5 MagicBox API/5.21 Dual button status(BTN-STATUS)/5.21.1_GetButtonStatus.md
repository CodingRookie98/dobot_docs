**Get red and blue button status**

request params：

|           |         |           |                                   |
|-----------|---------|-----------|-----------------------------------|
|  field    | type    |  required |  explain                          |
|  portName |  string |  yes      |  communication port of the device |
|  port     |  int    |  yes      |  communication port （0~5）       |

response result：

|          |       |                      |
|----------|-------|----------------------|
|  field   |  type |  explain             |
|  blueBtn |  int  |  0: Press, 1: Bounce |
|  redBtn  |  int  |  0: Press, 1: Bounce |

 

**KeyWords:**

portName: string

port: int (0~5) the port number of the red and blue button sensor
inserted into the magicianbox

INPUT:

{  
     \"id\": 1,  
     \"jsonrpc\": \"2.0\",  
     \"method\": \"dobotlink.MagicBox.GetButtonStatus\",  
     \"params\": {  
         \"port\": 0,  
         \"portName\": \"COM4\"  
     }  
 }

OUTPUT:

 {  
     \"id\": 1,  
     \"jsonrpc\": \"2.0\",  
     \"result\": {  
         \"blueBtn\": 1,  
         \"redBtn\": 1  
     }  
 }
