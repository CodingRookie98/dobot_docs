**Get whether an event of human infrared sensor is triggered**

request params

|           |         |            |                                   |
|-----------|---------|------------|-----------------------------------|
|  field    |  type   |  required  | explain                           |
|  portName |  string |  yes       |  communication port of the device |
|  port     |  int    |  yes       | communication port (0~5)          |

response result

|        |       |            |                                            |
|--------|-------|------------|--------------------------------------------|
|  field |  type |  required  | explain                                    |
|  res   | int   |  yes       | 1: event not triggered, 0: event triggered |

**KeyWords:**

portName: string

port: int (0~5)

INPUT:

``` language-json

{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicBox.IsPirDetected",
    "params": {
        "portName": "COM4",
        "port": 2
    }
}
```

OUTPUT:

``` language-json
{
    "id": 1,
    "jsonrpc": "2.0",
    "result": {
        "res": 1
    }
}
```
