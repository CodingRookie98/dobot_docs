# 4.10 Point to point motion command(PTP)

ptpMode:

 ul,li { list-style:none; } 
0: door movement, the parameter is the target point parameter

1: Joint motion parameters are target point parameters

2: Linear motion, the parameter is the target point parameter

3: Door motion, the parameter is the joint angle of the target point

4: Joint motion, the parameter is the joint angle of the target point

5: Linear motion, the parameter is the joint angle of the target point

6: Joint motion increment mode, the parameter is the joint angle increment of the target point

7: Linear motion increment mode, the parameter is the target point coordinate increment

8: Joint motion increment mode, the parameter is the target point coordinate increment

9: Door movement, the movement mode is linear movement when translating 





The default motion timeout is 5S. For configuration, please provide the timeout field.
