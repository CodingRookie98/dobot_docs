# 12.4.1 IsJoystickButton

Gets whether an event on the rocker is triggered

request params


| field | type | required | explain |
| --- | --- | --- | --- |
| portName | string | yes | communication port of the device |
| port | int | yes | communication port (0~5) |
| index | int | yes | rocker index (0: front, 1: rear, 2: left, 
      3: right, 4: 
bottom) |



response result


| field | type | required | explain |
| --- | --- | --- | --- |
| res | int | yes | 0: event not triggered, 1: event 
    triggered |





KeyWords:

portName: string

port: int (0~5)

 index: 0: front, 1: rear, 2: left, 3: right, 4: bottom
