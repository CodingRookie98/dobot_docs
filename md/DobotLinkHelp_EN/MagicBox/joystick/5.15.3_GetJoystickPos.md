# 12.4.3 GetJoystickPos

Get rocker position

request params


| field | type | required | explain |
| --- | --- | --- | --- |
| portName | string | yes | communication port of the device |
| port | int | yes | communication port  (0~5) |





response result


| field | type | required | explain |
| --- | --- | --- | --- |
| x | int | yes | value of rocker x-axis 0-255 |
| y | int | yes | value of rocker y-axis 0-255 |
| z | int | yes | value of rocker z-axis 
0-255 |



KeyWords:

portName: string 

port: int (0~5)

INPUT:

```json

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicBox.GetJoystickPos",
    "params": {
        "portName": "COM4",
        "port": 2
    }
}
```json

```

OUTPUT：

```json

```json
{    "id": 1,    "jsonrpc": "2.0",    "result": {        "x": 255,        "y": 255,        "z": 255    }}
```
