# 12.4.2 GetJoystickButton

Get all triggered events of the rocker

request params


| field | type | required | explain |
| --- | --- | --- | --- |
| portName | string | yes | communication port of the device |
| port | int | yes | port number  (0~5) |



response result


| field | type | required | explain |
| --- | --- | --- | --- |
| res | array（int） | yes | the 
      array length is the number of trigger events, and the array content is the 
      trigger events |





KeyWords:

portName: string

port: int (0~5)

 res: 0: front, 1: rear, 2: left, 3: right, 4: bottom

INPUT:

```json

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicBox.GetJoystickButton",
    "params": {
        "portName": "COM4",
        "port": 2
    }
}
```json

```

```json

```

OUTPUT：

```json

```json
{    "id": 1,    "jsonrpc": "2.0",    "result": {        "res": [1, 2]    }
}
