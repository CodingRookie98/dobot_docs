# 12.2.1 IsSensorHandModel

Gets whether the gesture sensor is triggered at a certain time

request params


| field | type | required | explain |
| --- | --- | --- | --- |
| portName | string | yes | communication port of the device |
| port | int | yes | communication port (0~5) |
| data | int | yes | Gesture recognition value: 64: draw a 
      circle clockwise, 128: draw a circle counterclockwise, 255: no 
  gesture |



response result


| field | type | required | explain |
| --- | --- | --- | --- |
| data | int | yes | 0: event not triggered, 1: event 
    triggered |





KeyWords:

portName: string

port: int (0~5)

data: 64: draw a circle clockwise, 128: draw a circle counterclockwise, 255: no gesture

```json
