# 8.14.16 SetSystemTime

Description: 系统时间设置

KeyWords:

portName: string

data: object



INPUT:

```json

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicianPro.SetSystemTime",

        "data": {

        }
    }
}
