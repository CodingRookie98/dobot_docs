# 8.10.3 SetDIValue

Description: 设置模拟模式下的数值

KeyWords:

portName: string

data: object



INPUT:

```json

{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicianPro.SetDIValue",
    "params": {
        "portName": "192.168.1.6",
        "data": {
            "index" : 10,
            "value" : 0 
        }
    }
}
```
