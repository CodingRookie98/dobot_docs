# 8.3.19 GetisCollision

Description: 获取是否发生了碰撞 

KeyWords:

portName: string

value: int (0/1),0未发生碰撞，1发生碰撞



INPUT:

```json

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicianPro.GetisCollision",
    "params": {
        "portName": "192.168.1.6"
    }
}
```
