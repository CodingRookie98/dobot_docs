# 8.9.2 GetEthernet

KeyWords:

portName: string



INPUT:

```json

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicianPro.GetEthernet",
    "params": {
        "portName": "192.168.1.6"
    }
}
```



OUTPUT:

```json

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "result": {
        "dhcp": false,
        "ip": "192.168.5.105",
        "netmask": "255.255.255.0",
        "gateway": "192.168.0.1"
    }
}
```
