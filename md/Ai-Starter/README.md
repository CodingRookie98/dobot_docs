# AI-Starter 智能小车用户手册

![AI-Starter 小车封面](images/starter_img-000.png)


AI-Starter 是一款针对教育、比赛推出的智能小车，采用了免焊接式安装设计，接线清晰，兼容 Arduino Mega2560 开发板。
