# DobotLink API 文档

本目录包含 DobotLink API 文档的不同语言版本。

## 目录结构

```
./
├── DobotLinkHelp/          中文版本 API 文档
├── DobotLinkHelp_EN/       英文版本 API 文档
└── DOBOT_EDU_API.md        DobotEDU Python SDK 接口文档
```

## 版本说明

- **DobotLinkHelp/**：从 DobotLinkHelp.CHM 转换而来的中文版本 API 文档，包含完整索引
- **DobotLinkHelp_EN/**：英文版本 API 文档，结构与中文版本一致
- **DOBOT_EDU_API.md**：额外的 DobotEDU Python SDK 接口文档

每个语言版本目录内都有自己的 README 说明文档结构。
