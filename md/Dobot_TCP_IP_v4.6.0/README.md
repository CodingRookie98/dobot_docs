### 🛠️ Dashboard API 接口详解 (29999 端口)
Dashboard 接口用于机器人控制、参数配置、运动下发等。接口分为以下 7 大子模块：

| 模块分类 | 接口数 | 描述 | 子文档直达 |
| :--- | :---: | :--- | :--- |
| **3.1 机器人系统控制** | 13 | 机械臂上电、使能、清除报警、拖拽示教、脚本工程运行及紧急停止等 | [👉 机器人系统控制文档](03_1_机器人系统控制.md) |
| **3.2 全局设置与参数配置** | 15 | 关节及直线运动的全局速度/加速度比例、末端负载、平滑过渡、碰撞等级配置 | [👉 全局设置与配置文档](03_2_设置相关指令.md) |
| **3.3 信息查询与运动学计算** | 7 | 查询当前坐标、关节角、报警ID、正向运动学(FK)及逆向运动学(IK)计算 | [👉 信息查询与计算文档](03_3_信息查询与运动学计算.md) |
| **3.4 IO 与外设控制** | 16 | 控制柜与末端工具的数字 (DO/DI) 及模拟量 (AO/AI) 的读写及配置 | [👉 IO与外设控制文档](03_4_IO与外设控制.md) |
| **3.5 Modbus 与总线寄存器** | 12 | 机器人作为 Modbus 主站进行数据读写，以及 Profinet/EthernetIP 寄存器操作 | [👉 总线通信与Modbus文档](03_5_Modbus与总线寄存器.md) |
| **3.6 运动控制指令** | 22 | 关节运动 (MovJ)、直线运动 (MovL)、实时跟随模式 (ServoJ/P) 及 Jog 点动控制 | [👉 运动轨迹控制文档](03_6_运动控制指令.md) |
| **3.7 高级功能 (力控、轨迹恢复、日志)** | 22 | 焊接轨迹智能恢复、控制柜日志 U 盘导出，以及恒力/柔顺控制与力传感器皮重置零 | [👉 高级与力控开发文档](03_7_高级功能.md) |
