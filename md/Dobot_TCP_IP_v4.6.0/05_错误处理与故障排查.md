# 错误处理与故障排查

## 1. Dashboard 指令返回错误码 (ErrorID)

所有 Dashboard 指令在执行后都会返回一个 `ErrorID`。其中 `0` 表示执行成功，负值表示不同类型的错误。

| 错误码 | 简述 | 详细描述 / 解决建议 |
| :---: | :--- | :--- |
| **0** | 无错误 | 命令下发并接收执行成功。 |
| **-1** | 命令执行失败 | 已收到命令但执行逻辑失败（例如：在未使能或未上电时下发了运动控制指令）。 |
| **-2** | 机器人报警中 | 机器人当前处于报警状态。需排查故障，并调用 `ClearError` 指令清除报警。 |
| **-3** | 机器人急停中 | 紧急停止已按下。需松开急停按钮，并调用 `ClearError` 清除报警。 |
| **-4** | 机械臂下电中 | 机械臂处于下电状态。需调用 `PowerOn` 上电。 |
| **-5** | 脚本运行中 | 正在执行后台 Lua 脚本，部分在线交互指令被拒绝。需先停止脚本。 |
| **-6** | MoveJog运动轴不匹配 | `MoveJog` 指令中的运动轴与当前的坐标系类型（关节/笛卡尔）不匹配。 |
| **-7** | 脚本暂停中 | 后台 Lua 脚本处于暂停状态，拒绝执行部分指令。需停止脚本。 |
| **-8** | 认证过期或无权限 | 机械臂认证过期，处于不可用状态，或当前连接未通过 `RequestControl` 请求控制权。 |
| **-10000** | 命令不存在 | 下发的指令名称不存在。请检查拼写，Dashboard 端口不区分大小写。 |
| **-20000** | 参数数量错误 | 下发的参数个数与该指令的原型定义不符。 |
| **-3000X** | 必选参数类型错误 | 第 `X` 个必选参数的数据类型错误（尾数 `X` 表示参数索引）。 |
| **-4000X** | 必选参数范围错误 | 第 `X` 个必选参数的数值超限或不在合法范围内。 |
| **-5000X** | 可选参数类型错误 | 携带的可选参数（如 `user=1`）的数据类型错误。 |
| **-6000X** | 可选参数范围错误 | 携带的可选参数的值超出了合法范围。 |

---

## 2. 常见问题排查步骤

1.  **返回 `-10000` (命令不存在)**：
    请检查命令的拼写。注意所有命令必须以括号结尾（例如：应使用 `EnableRobot()`，而不是 `EnableRobot`）。虽然命令不区分大小写，但参数名称（如可选参数 `user=1`）必须拼写正确。
2.  **指令无任何返回**：
    Dashboard 端口（29999）默认使用 **ASCII 字符串** 进行交互，所有的下发指令必须以换行符（如 `\n` 或 `\r\n`）结束，否则服务器将一直等待输入。
3.  **返回 `-8` (无控制权)**：
    在下发任何控制指令（如 `EnableRobot`、`MovJ`）前，必须确保首先发送了 `RequestControl()` 并收到成功返回，将控制器控制权切换到当前 TCP 客户端。
