# 常见问题与示例 (FAQ & Examples)

## 7. 常见问题与示例 (FAQ & Examples)

### 7.1 典型开发流程示例

**1. 初始化与使能：**
```
RequestControl()        // 1. 请求控制权
PowerOn()               // 2. 机器人上电 (需等待约10s)
EnableRobot(1.5, 0, 0, 30) // 3. 使能并设置负载 (1.5kg, 偏移30mm)
```

**2. 简单运动控制：**
```
SpeedFactor(50)         // 设置全局速率 50%
MovJ(joint={0,0,90,0,90,0}, v=80) // 关节运动
MovL(pose={500,0,200,180,0,0}, speed=500) // 直线运动
```

**3. IO 与运动并发：**
```
// 当运动到 50% 距离时，自动开启 1 号数字输出
MovLIO(joint={10,10,10,0,0,0}, {0,50,1,1}) 
```

### 7.2 参数错误示例分析 (避坑指南)

- **错误示例 1**：`MovJ(joint="a", ...)` -> 返回 `-30001` (第一个必选参数类型错误)。
- **错误示例 2**：`DO(1, "2")` -> 返回 `-30002` (第二个必选参数类型错误，应为 int)。
- **错误示例 3**：`SetUser(1, {0,0,100,0,0,0}123, 1)` -> 返回 `-20000` (由于花括号后有冗余字符，参数数量解析错误)。
