## 2.8 ShowMessage

**Description: 显示dobotlink正在运行的弹窗**

**KeyWords:**

title: string

message: string

INPUT:

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.api.ShowMessage",
    "params": {
        "title": "Information",
        "message": "DobotLink is running."
    }
}
```
