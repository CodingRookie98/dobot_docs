### 12.5.1 GetButtonStatus

**获取红蓝按钮状态**

请求参数 params：

  ----------- --------- ----------- -----------------
  字段       类型     是否必填   说明
  portName   string   是         通信端口
  port       int      是         端口号（0~5）
  ----------- --------- ----------- -----------------

响应参数result：

  ---------- ------- -------------------
  参数名    类型   说明
  blueBtn   int    0：按下，1：弹起
  redBtn    int    0：按下，1：弹起
  ---------- ------- -------------------

**KeyWords:**

portName: string

port: int (0~5) 红蓝按钮传感器插入到MagicianBox上的端口号

INPUT:

{style="BACKGROUND-COLOR: #f5f2f0"}
{
 "id": 1,
 "jsonrpc": "2.0",
 "method": "dobotlink.MagicBox.GetButtonStatus",
 "params": {
 "port": 0,
 "portName": "COM4"
 }
}
OUTPUT:

{style="BACKGROUND-COLOR: #f5f2f0"}
{
 "id": 1,
 "jsonrpc": "2.0",
 "result": {
 "blueBtn": 1,
 "redBtn": 1
 }
}
