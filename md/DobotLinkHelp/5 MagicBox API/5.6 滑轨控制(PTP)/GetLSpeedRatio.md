### 5.6.3 GetLSpeedRatio

**获取导轨速度比例**

请求参数 params

+-----------------+-----------------+-----------------+-----------------+
| 字段           | 类型          | 是否必填      | 说明          |
+-----------------+-----------------+-----------------+-----------------+
| portName       | string         | 是             | 通信端口       |
+-----------------+-----------------+-----------------+-----------------+
| type           | int            | 是             | <div>           |
|                 |                 |                 |                 |
|                 |                 |                 | [               |
|                 |                 |                 | 速度参数       |
|                 |                 |                 | 类型（0:JOG、1: |
|                 |                 |                 | PTP）]{style="F |
|                 |                 |                 | ONT-SIZE: 9pt;  |
|                 |                 |                 | FONT-FAMILY: 黑 |
|                 |                 |                 | 体; COLOR: rgb  |
|                 |                 |                 | (0,0,0); mso-sp |
|                 |                 |                 | acerun: 'yes'"} |
|                 |                 |                 |                 |
|                 |                 |                 | </div>          |
+-----------------+-----------------+-----------------+-----------------+

响应参数 result

+-----------------+-----------------+-----------------+-----------------+
| 字段           | 类型          | 是否必填      | 说明          |
+-----------------+-----------------+-----------------+-----------------+
| value           | int             | 是             | 速度           |
|                 |                 |                 | 比例值（0~100  |
|                 |                 |                 | unit:%）        |
+-----------------+-----------------+-----------------+-----------------+
| type           | int            | 是             | <div>           |
|                 |                 |                 |                 |
|                 |                 |                 | [速度参数      |
|                 |                 |                 | 类型（0:JOG、1: |
|                 |                 |                 | PTP）]{style="F |
|                 |                 |                 | ONT-SIZE: 9pt;  |
|                 |                 |                 | FONT-FAMILY: 黑 |
|                 |                 |                 | 体; COLOR: rgb  |
|                 |                 |                 | (0,0,0); mso-sp |
|                 |                 |                 | acerun: 'yes'"} |
|                 |                 |                 |                 |
|                 |                 |                 | </div>          |
+-----------------+-----------------+-----------------+-----------------+

**KeyWords:**

portName: string

type: int 速度参数类型 0:JOG,1:PTP

INPUT:

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicBox.GetLSpeedRatio",
    "params": {
        "portName": "COM4",
        "type": 0
    }
}
```

OUTPUT:

```json
{
 "id": 1,
 "jsonrpc": "2.0",
 "result": {
 "type": 0,
 "value": 50
 }
}
```
