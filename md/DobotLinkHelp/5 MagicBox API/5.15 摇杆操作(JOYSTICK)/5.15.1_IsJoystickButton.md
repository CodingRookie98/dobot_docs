**获取摇杆某个事件是否被触发**

请求参数 params

  ----------- --------- ----------- -----------------------------------------------
   字段       类型      是否必填    说明 
   portName    string    是          通信端口
   port        int       是          端口号(0\~5)
   index       int       是         摇杆索引（0:前，1：后，2：左，3：右，4：下 ）
  ----------- --------- ----------- -----------------------------------------------

响应参数 result

  ------- ------- ----------- -------------------------------
   字段   类型    是否必填    说明 
   res    int      是          0：事件无触发，1：事件被触发
  ------- ------- ----------- -------------------------------

 

**KeyWords:**

portName: string
