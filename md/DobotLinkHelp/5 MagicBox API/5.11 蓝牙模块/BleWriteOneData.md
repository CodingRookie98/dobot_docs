### 5.11.6 BleWriteOneData

**蓝牙数据发送，仅适用于蓝牙主机模式，只发送一个数据**

请求参数 params

  ----------- --------- ----------- -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  字段       类型     是否必填   说明
  portName   string   是         通信端口
  data       string   是         数据内容，长度在 [14]{style="FONT-SIZE: 10.45pt; FONT-FAMILY: Calibri; COLOR: rgb(0,0,0); mso-spacerun: 'yes'"}[字节以内，不足部分填充]{style="FONT-SIZE: 10.45pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0); mso-spacerun: 'yes'"}[0]{style="FONT-SIZE: 10.45pt; FONT-FAMILY: Calibri; COLOR: rgb(0,0,0); mso-spacerun: 'yes'"}
  ----------- --------- ----------- -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
响应参数 result

  --------- -------- ------------ --------------------------------------------
  字段     类型   是否必填   说明
  result   bool    是          响应结果（true:操作成功，false:操作失败）
  --------- -------- ------------ --------------------------------------------

**KeyWords:**

portName: string

data: string

INPUT:

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicBox.BleWriteOneData",
    "params": {
        "portName": "COM4" ,
        "data": "1"
    }
}
```

OUTPUT：

```json
{
 "id": 1,
 "jsonrpc": "2.0",
 "result": true
}
```
