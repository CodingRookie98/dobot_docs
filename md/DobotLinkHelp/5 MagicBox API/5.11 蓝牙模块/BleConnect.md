### 5.11.4 BleConnect

**设置蓝牙连接，仅适用于蓝牙主机模式，蓝牙会扫描并连接指定名字的从机**

请求参数 params

  ----------- --------- ----------- ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  字段       类型     是否必填   说明
  portName   string   是         通信端口
  time       int      是         连接超时时间，单位秒
  name       string   是          [字符串，长度在]{style="FONT-SIZE: 10.45pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0); mso-spacerun: 'yes'"} [14]{style="FONT-SIZE: 10.45pt; FONT-FAMILY: Calibri; COLOR: rgb(0,0,0); mso-spacerun: 'yes'"} [字节以内，不足部分填充]{style="FONT-SIZE: 10.45pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0); mso-spacerun: 'yes'"} [0]{style="FONT-SIZE: 10.45pt; FONT-FAMILY: Calibri; COLOR: rgb(0,0,0); mso-spacerun: 'yes'"}
  ----------- --------- ----------- ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
响应参数 result

  --------- -------- ------------ --------------------------------------------
  字段     类型   是否必填   说明
  result   bool    是          响应结果（true:操作成功，false:操作失败）
  --------- -------- ------------ --------------------------------------------

**KeyWords:**

portName: string

time: int，连接超时时间，单位秒

name: string，长度在14字节以内

INPUT:

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicBox.BleConnect",
    "params": {
        "portName": "COM4" ,
        "time": 100,
        "name": "string"
    }
}
```

OUTPUT：

```json
{
 "id": 1,
 "jsonrpc": "2.0",
 "result": true
}
```
