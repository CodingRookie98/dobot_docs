### 12.3.1 IsPirDetected

**获取人体红外传感器某个事件是否被触发**

请求参数 params

  ----------- --------- ----------- ---------------
  字段       类型     是否必填   说明
  portName   string   是         通信端口
  port       int      是         端口号(0~5)
  ----------- --------- ----------- ---------------

响应参数 result

  ------- ------- ----------- -------------------------------
  字段   类型   是否必填   说明
  res    int     是         1：事件无触发，0：事件被触发
  ------- ------- ----------- -------------------------------

**KeyWords:**

portName: string

port: int (0~5)

INPUT:

```json

{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicBox.IsPirDetected",
    "params": {
        "portName": "COM4",
        "port": 2
    }
}
```

OUTPUT:

```json
{
 "id": 1,
 "jsonrpc": "2.0",
 "result": {
 "res": 1
 }
}
```
