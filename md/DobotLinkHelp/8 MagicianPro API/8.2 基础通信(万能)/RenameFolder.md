### 8.2.10 RenameFolder

**Description: 重命名文件夹**

**KeyWords:**

portName: string

folderName: string（原来的文件名）

newfolderName: string（新的文件名）

INPUT:

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicianPro.RenameFolder",
    "params": {
        "portName": "192.168.1.6",
        "folderName": "/xxx/xxx",
        "newfolderName": "/xxx/xxx"
    }
}
```
