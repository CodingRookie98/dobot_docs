### 8.14.27 SetTruemotion

**Description: 开启/关闭Truemotion功能**

**KeyWords:**

portName: string

UsingTrueMotion: bool

INPUT:

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicianPro.SetTruemotion",
    "params": {
        "portName": "192.168.1.6",
        "data": {
            "UsingTrueMotion" : true
        }
    }
}
```
