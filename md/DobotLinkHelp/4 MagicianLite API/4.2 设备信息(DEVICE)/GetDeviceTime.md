**KeyWords:**

portName: string

gSystick: int

passtime: string

INPUT:

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "dobotlink.MagicianLite.GetDeviceTime",
    "params": {
        "portName": "COM4"
    }
}
```

OUTPUT:

```json
{
 "id": 1,
 "jsonrpc": "2.0",
 "result": {
 "gSystick": 60956409,
 "passtime": "16:55:56.409"
 }
}
```
