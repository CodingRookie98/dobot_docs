## 2. 通讯架构与协议说明

### 2.1 端口说明
 Dobot 机器人开启以下服务器端口用于对外交互：

| 端口号 | 名称 | 功能描述 | 反馈频率 |
| :--- | :--- | :--- | :--- |
| **29999** | **Dashboard** | 用于发送控制指令或主动获取机器人状态（ASCII 格式）。 | 主动请求式 |
| **30004** | **实时反馈** | 客户端每 8ms 收到一次机器人实时状态信息（1440 字节二进制包）。 | 8ms |
| **30005** | **信息反馈** | 每 200ms 反馈一次机器人的信息。 | 200ms |
| **30006** | **可配置反馈** | 可配置端口（默认为 50ms 反馈，可通过技术支持修改）。 | 50ms |

### 2.2 Dashboard 消息格式 (29999 端口)
消息命令与消息应答均采用 **ASCII 码格式 (字符串形式)**，不区分大小写。

#### 2.2.1 上位机下发格式
`消息名称(Param1, Param2, ..., ParamN)`
- 参数之间以英文逗号 `,` 分隔。
- 完整的消息以右括号 `)` 结束。
- 示例：`EnableRobot()`

#### 2.2.2 机器人应答格式
`ErrorID, {value1, value2, ..., valueN}, 消息名称(Param1, Param2, ..., ParamN);`
- **ErrorID**: 0 表示接收成功，非 0 表示错误（详见章节：通用错误码）。
- **{value, ...}**: 返回值列表。若无返回值则返回 `{}`。
- **消息名称(...)**: 下发的原始命令消息。

### 2.3 指令执行逻辑
- **立即指令 (Immediate)**：系统无视指令队列，在读到指令后立刻执行（如：`DOInstant`）。
- **队列指令 (Queue)**：系统会等待之前的指令队列执行完毕后再执行本指令（如：常规的 `DO` 指令）。
- *注：如无特殊说明，读取输入的指令均为立即指令。*

## 3. Dashboard 接口 API 详解 (29999 端口)

 Dashboard 接口指令通常为立即指令（除非另有说明），用于控制机器人状态、运动及获取基本信息。

### 3.1 机器人系统控制 (System Control)

本节指令主要用于机械臂的上电、使能、报警清除、脚本执行及紧急停止等系统级状态切换。

| 指令 | 功能 | 类型 |
| :--- | :--- | :--- |
| `RequestControl` | 请求将设备控制模式切换为 TCP 模式 | 立即指令 |
| `PowerOn` | 机器人上电 | 立即指令 |
| `EnableRobot` | 使能机器人 | 立即指令 |
| `DisableRobot` | 下使能机器人 | 立即指令 |
| `ClearError` | 清除机器人报警 | 立即指令 |
| `RunScript` | 运行指定工程 | 立即指令 |
| `Stop` | 停止运动或正在运行的工程 | 立即指令 |
| `Pause` | 暂停运动或正在运行的工程 | 立即指令 |
| `Continue` | 继续运动或已暂停的工程 | 立即指令 |
| `EmergencyStop` | 紧急停止机器人 | 立即指令 |
| `BrakeControl` | 控制指定关节的抱闸 | 立即指令 |
| `StartDrag` | 机器人进入关节拖拽模式 | 立即指令 |
| `StopDrag` | 机器人退出拖拽模式 | 立即指令 |

---

#### 3.1.1 RequestControl
- **原型**：`RequestControl()`
- **描述**：请求将设备控制模式切换为 TCP 模式。只有在该模式下才可执行其他 TCP 指令。仅当机器人处于未上电或下使能（且非暂停或松抱闸状态）时才可切换。
- **返回**：`ErrorID, {}, RequestControl();`

#### 3.1.2 PowerOn
- **原型**：`PowerOn()`
- **描述**：机器人上电。上电完成约需 10 秒，完成后方可进行使能操作。请勿在开机初始化完成前下发控制信号。
- **返回**：`ErrorID, {}, PowerOn();`

#### 3.1.3 EnableRobot
- **原型**：`EnableRobot([load, centerX, centerY, centerZ, isCheck])`
- **描述**：使能机器人。
- **参数**：
  - `load` (double): 负载重量 (kg)。
  - `centerX/Y/Z` (double): X/Y/Z 方向偏心距离 (mm)。
  - `isCheck` (int): 是否检查负载 (0: 不检查, 1: 检查)。若设置且负载不一致，使能后会自动下使能。
- **返回**：`ErrorID, {}, EnableRobot(...);`

#### 3.1.4 DisableRobot
- **原型**：`DisableRobot()`
- **描述**：下使能机器人。
- **返回**：`ErrorID, {}, DisableRobot();`

#### 3.1.5 ClearError
- **原型**：`ClearError()`
- **描述**：清除机器人报警。部分报警可能需要排除故障或重启控制柜。
- **返回**：`ErrorID, {}, ClearError();`

#### 3.1.6 RunScript
- **原型**：`RunScript(projectName)`
- **参数**：`projectName` (string): 工程文件名称。中文需 UTF-8 编码；纯数字需加双引号。
- **描述**：运行指定工程。
- **返回**：`ErrorID, {}, RunScript(projectName);`

#### 3.1.7 Stop / Pause / Continue
- **原型**：`Stop()` / `Pause()` / `Continue()`
- **描述**：停止、暂停或继续已下发的运动指令队列或正在运行的工程。
- **返回**：`ErrorID, {}, 指令名称();`

#### 3.1.8 EmergencyStop
- **原型**：`EmergencyStop(mode)`
- **参数**：`mode` (int): 1 为按下急停，0 为松开。
- **描述**：急停后机器人会下使能并报警。
- **返回**：`ErrorID, {}, EmergencyStop(mode);`

#### 3.1.9 BrakeControl
- **原型**：`BrakeControl(axisID, value)`
- **参数**：
  - `axisID` (int): 关节序号 (1~6)。
  - `value` (int): 0 为抱闸锁死，1 为松开抱闸。
- **描述**：仅能在机器人下使能时控制建议手动扶住关节。
- **返回**：`ErrorID, {}, BrakeControl(axisID, value);`

#### 3.1.10 StartDrag / StopDrag
- **原型**：`StartDrag()` / `StopDrag()`
- **描述**：进入/退出关节拖拽模式（退出指令对力控拖拽同样有效）。
- **返回**：`ErrorID, {}, 指令名称();`

### 3.2 运动控制指令 (Motion Commands)

运动指令通常为队列指令，支持关节运动、直线运动、圆弧运动等多种轨迹规划方式。所有点位支持关节角（`joint`）或位姿（`pose`）两种表达方式。

#### 3.2.1 运动参数说明
- **速度与加速度比例 (`v`, `a`)**：取值 [1, 100]，相对于最大速度/加速度的百分比。
- **绝对速度 (`speed`)**：单位 mm/s，仅在直线/圆弧运动有效，不受全局速率影响。
- **平滑过渡 (`cp`, `r`)**：
  - `cp`: 平滑过渡比例 [0, 100]。
  - `r`: 平滑过渡半径 (mm)。

#### 3.2.2 基础轨迹指令

| 指令 | 功能 | 类型 |
| :--- | :--- | :--- |
| `MovJ` | 关节空间运动至目标点 | 队列指令 |
| `MovL` | 直线轨迹运动至目标点 | 队列指令 |
| `Arc` | 圆弧轨迹运动 (需起点、中间点、终点) | 队列指令 |
| `Circle` | 整圆轨迹运动 (需起点、中间点、终点) | 队列指令 |

- **原型示例**：
  - `MovJ(p, [user, tool, a, v, cp])`
  - `MovL(P, [user, tool, a, v, speed, cp, r])`
  - `Arc(P1, P2, [user, tool, a, v, speed, cp, r, ori_mode])`
  - `Circle(P1, P2, [user, tool, a, v, speed, count])`

#### 3.2.3 运动并发 IO (Motion + DO)
在运动过程中指定位置触发数字输出。
- `MovLIO(P, {Mode,Distance,Index,Status}, [user, tool, a, v, speed, cp, r])`
- `MovJIO(P, {Mode,Distance,Index,Status}, [user, tool, a, v, cp])`
  - `Mode`: 0 (百分比), 1 (距离/角度数值)。
  - `Distance`: 触发位置（正值从起点计，负值从终点计）。

#### 3.2.4 实时跟随指令 (Servo Mode)
用于外部上位机实时下位机路径。
- `ServoJ(P, [t])`：基于关节空间的动态跟随。
- `ServoP(P, [t])`：基于笛卡尔空间的动态跟随。

#### 3.2.5 相对运动与偏移 指令
- **工具坐标系偏移**：`RelMovJTool`, `RelMovLTool`, `RelPointTool`
- **用户坐标系偏移**：`RelMovJUser`, `RelMovLUser`, `RelPointUser`
- **关节对应偏移**：`RelJointMovJ`, `RelJoint`

#### 3.2.6 点动与运行 (Jog & Tool)
- `MoveJog(axisID, [coordtype, user, tool])`：点动机械臂。
- `RunTo(p)`：运动至指定点位。

#### 3.2.7 轨迹复现
- `StartPath(pathName, [const, count])`：复现已录制的运动轨迹。
- `GetStartPose(pathName)`：获取轨迹起点。

### 3.3 IO 与外设控制 (IO & Peripherals)

本节涵盖了控制柜数字/模拟 IO、末端工具 IO 以及 Modbus 通讯相关指令。

#### 3.3.1 控制柜数字与模拟 IO

| 指令 | 功能 | 类型 | 参数说明 |
| :--- | :--- | :--- | :--- |
| `DO` | 设置数字输出状态 | 队列指令 | `index, status, [time]` |
| `DOInstant` | 立即设置数字输出状态 | 立即指令 | `index, status` |
| `GetDO` | 获取数字输出状态 | 立即指令 | `index` |
| `DI` | 获取数字输入状态 | 立即指令 | `index` |
| `AO` | 设置模拟输出值 | 队列指令 | `index, value` |
| `AOInstant` | 立即设置模拟输出值 | 立即指令 | `index, value` |
| `GetAO` | 获取模拟输出值 | 立即指令 | `index` |
| `AI` | 获取模拟输入值 | 立即指令 | `index` |

#### 3.3.2 末端工具 IO 与配置

| 指令 | 功能 | 类型 |
| :--- | :--- | :--- |
| `ToolDO` | 设置末端数字输出 | 队列指令 |
| `ToolDOInstant` | 立即设置末端数字输出 | 立即指令 |
| `GetToolDO` | 获取末端数字输出状态 | 立即指令 |
| `ToolDI` | 获取末端数字输入状态 | 立即指令 |
| `ToolAI` | 获取末端模拟输入值 | 立即指令 |
| `SetTool485` | 设置末端 485 通讯格式 | 立即指令 |
| `SetToolPower` | 设置末端工具供电状态 | 立即指令 |
| `SetToolMode` | 设置末端复用端子的模式 | 立即指令 |

#### 3.3.3 Modbus 通讯接口

机器人作为 Modbus TCP/RTU 主站，最多支持同时连接 5 个设备。

| 指令 | 功能描述 |
| :--- | :--- |
| `ModbusCreate` | 创建 Modbus TCP/RTU 主站并连接 |
| `ModbusRTUCreate` | 创建基于 RS485 的 Modbus 主站 |
| `ModbusClose` | 断开 Modbus 连接并释放主站 |
| `GetInBits` | 读取触点寄存器 (Discrete Inputs) |
| `GetInRegs` | 读取输入寄存器 (Input Registers) |
| `GetCoils` | 读取线圈寄存器 (Coils) |
| `SetCoils` | 写入线圈寄存器 |
| `GetHoldRegs` | 读取保持寄存器 (Holding Registers) |
| `SetHoldRegs` | 写入保持寄存器 |

- **地址范围**：根据从站定义，`count` 范围通常为 [1, 4] 或 [1, 16]。

### 3.4 全局设置与参数配置 (Configuration & Settings)

本节指令用于配置坐标系、运动动态性能、负载以及安全限制。

#### 3.4.1 坐标系标定与选择

| 指令 | 功能 | 类型 | 参数说明 |
| :--- | :--- | :--- | :--- |
| `User` | 设置全局用户坐标系 | 立即指令 | `index` (0~50) |
| `SetUser` | 修改指定的用户坐标系 | 立即指令 | `index, value, [type]` |
| `CalcUser` | 计算用户坐标系偏移 | 立即指令 | `index, matrix, offset` |
| `Tool` | 设置全局工具坐标系 | 立即指令 | `index` (0~50) |
| `SetTool` | 修改指定的工具坐标系 | 立即指令 | `index, value, [type]` |
| `CalcTool` | 计算工具坐标系偏移 | 立即指令 | `index, matrix, offset` |

- **注**：`type=1` 表示保存到控制器，退出 TCP 模式后依然生效。

#### 3.4.2 运动性能与负载

| 指令 | 功能 | 类型 | 默认值 |
| :--- | :--- | :--- | :--- |
| `SpeedFactor` | 设置全局速度比例 | 立即指令 | - |
| `SetPayload` | 设置机械臂末端负载 | 队列指令 | - |
| `AccJ / VelJ` | 设置关节运动加/速度比例 | 立即指令 | 100 |
| `AccL / VelL` | 设置直线运动加/速度比例 | 立即指令 | 100 |
| `CP` | 设置平滑过渡比例 | 立即指令 | 0 |

#### 3.4.3 安全与感知设置

这些设置通常沿用控制软件的配置，但可通过以下指令动态修改：

| 指令 | 功能描述 |
| :--- | :--- |
| `SetCollisionLevel` | 设置碰撞检测等级 (0~5) |
| `SetBackDistance` | 设置碰撞后的回退距离 (0~50mm) |
| `SetPostCollisionMode`| 设置碰撞后的状态 (0: 停止, 1: 暂停) |
| `DragSensivity` | 设置各轴拖拽灵敏度 (1~90) |
| `EnableSafeSkin` | 开启/关闭电子皮肤 |
| `SetSafeSkin` | 设置电子皮肤各部位灵敏度 |
| `SetWorkZoneEnable` | 开启/关闭指定安全区域 |

### 3.5 信息查询与运动学计算 (Information Acquisition)

本节指令用于查询机械臂实时状态、关节/笛卡尔坐标、报警代码以及执行正逆解运算。

#### 3.5.1 状态与报警查询

| 指令 | 功能 | 返回值说明 |
| :--- | :--- | :--- |
| `RobotMode` | 获取机器人当前模式 | 0: 初始化, 3: 下电, 4: 未使能, 5: 使能, 7: 运行, 9: 报错 |
| `GetErrorID` | 获取当前报错错误码 | 返回错误码数组 `[id1, id2, ...]` |

#### 3.5.2 坐标与位姿获取

| 指令 | 功能 | 参数 / 返回值 |
| :--- | :--- | :--- |
| `GetAngle` | 获取当前关节角度 | `{J1, J2, J3, J4, J5, J6}` |
| `GetPose` | 获取指定坐标系下的笛卡尔位姿 | 参数: `[user, tool]`，返回: `{x, y, z, rx, ry, rz}` |

#### 3.5.3 运动学计算 (Kinematics)

| 指令 | 功能 | 说明 |
| :--- | :--- | :--- |
| `PositiveKin` | 正解运算 | 关节角 -> 笛卡尔位姿 |
| `InverseKin` | 逆解运算 | 笛卡尔位姿 -> 关节角 (需通过 `jointNear` 指定倾向选解) |

- **InverseKin 特别说明**：由于一处位姿可能对应多个关节解，建议传入 `useJointNear=1` 并提供参考关节角以获得唯一解。

#### 3.5.4 托盘管理 (Tray API)

用于在空间中创建点阵（一维、二维或三维托盘）：

- `GetTrayPoint(Trayname, index)`：根据序号获取托盘内具体的点位坐标。

### 3.6 高级功能 (Advanced Functions)

本节包含轨迹恢复（主要针对焊接等工艺）、系统日志导出以及力控功能相关的指令。

#### 3.6.1 轨迹恢复 (Trajectory Recovery)

用于在工程暂停并手动点动机器人后，恢复至暂停时的点位：

| 指令 | 功能 | 类型 |
| :--- | :--- | :--- |
| `SetResumeOffset` | 设置轨迹恢复的回退距离 (焊接工艺适用) | 立即指令 |
| `PathRecovery` | 开始轨迹恢复 (使机器人回到暂停位姿) | 立即指令 (异步) |
| `PathRecoveryStop` | 停止轨迹恢复过程 | 立即指令 |
| `PathRecoveryStatus` | 查询轨迹恢复状态 | 立即指令 |

#### 3.6.2 日志导出 (Log Export)

| 指令 | 功能 | 说明 |
| :--- | :--- | :--- |
| `LogExportUSB` | 将系统日志导出至控制柜 U 盘 | 建议仅插入一个 U 盘，导出至根目录 |
| `GetExportStatus` | 获取日志导出进度/状态 | - |

#### 3.6.3 力控功能 (Force Control)

适用于安装了六维力传感器的机器人，支持力控拖拽和恒力控制。

| 指令 | 功能描述 |
| :--- | :--- |
| `EnableFTSensor` | 开启/关闭六维力传感器 |
| `SixForceHome` | 力传感器当前值回零 (去皮) |
| `GetForce` | 获取传感器当前受力数值 |
| `ForceDriveMode` | 进入力控拖拽模式 (可指定方向约束) |
| `ForceDriveSpeed` | 设置力控拖拽的速度比例 |
| `FCForceMode` | 开启恒力/柔顺控制模式 |
| `FCSetDeviation` | 设置力控模式下的位移/姿态偏差阈值 |
| `FCSetForceLimit` | 设置各方向的最大力限制 |
| `FCSetMass/Stiffness/Damping` | 设置力控系统的惯性、弹性、阻尼系数 |
| `FCSetForceSpeedLimit` | 设置各方向的力控调节速度限制 |
| `FCOff` | 退出力控模式 |

#### 3.6.4 总线寄存器 (Bus Registers)
用于读写 Profinet 或 Ethernet/IP 总线寄存器。

| 指令 | 功能描述 | 立即/队列 |
| :--- | :--- | :--- |
| `GetInputBool/Int/Float` | 获取输入寄存器指定地址的值 | 立即指令 |
| `GetOutputBool/Int/Float` | 获取输出寄存器指定地址的值 | 立即指令 |
| `SetOutputBool/Int/Float` | 设置输出寄存器指定地址的值 | 立即指令 |

- **地址范围**：`bool` 取值 [0, 63]，`int/float` 取值 [0, 23]。

## 4. 实时反馈接口详解 (30004~30006 端口)

实时反馈接口采用 **二进制 (Binary)** 数据包格式，机器人作为服务器循环发送当前状态。用户需按字节偏移量解析数据。

### 4.1 协议概要
- **数据包大小**：固定为 1440 字节。
- **反馈频率**：
  - 30004 端口：8ms (125Hz)
  - 30005 端口：200ms (5Hz)
  - 30006 端口：默认 50ms (可配置)

### 4.2 数据包结构映射 (部分核心字段)

| 字节偏移 | 字段名 | 数据类型 | 描述 |
| :--- | :--- | :--- | :--- |
| `0000~0001` | `MessageSize` | `ushort` | 消息总长度 |
| `0008~0015` | `DigitalInputs`| `uint64` | 数字输入状态 (位映射) |
| `0016~0023` | `DigitalOutputs`| `uint64` | 数字输出状态 (位映射) |
| `0024~0031` | `RobotMode` | `uint64` | 机器人模式 |
| `0032~0039` | `TimeStamp` | `uint64` | Unix 时间戳 (ms) |
| `0192~0239` | `QTarget` | `double[6]` | 目标关节位置 |
| `0432~0479` | `QActual` | `double[6]` | 实际关节位置 |
| `0624~0671` | `ToolVectorActual`| `double[6]` | TCP 笛卡尔实际坐标 |
| `0720~0767` | `TCPForce` | `double[6]` | TCP 受力值 |
| `1025` | `BrakeStatus` | `char` | 抱闸状态 (位映射) |
| `1030` | `CRRobotType` | `char` | 机器型号代码 |
| `1420` | `SafetyState` | `char` | 安全状态 (位映射) |

### 4.3 关键字段解析说明

#### 4.3.1 BrakeStatus (抱闸状态位映射)
按位表达各关节抱闸：`1` 为松开，`0` 为锁定。
- `Bit 0`: 关节 6
- `Bit 1`: 关节 5
- ...
- `Bit 5`: 关节 1

#### 4.3.2 SafetyState (安全状态位映射)
- `Bit 0`: 急停状态 (低有效)
- `Bit 1`: 防护性停止
- `Bit 4`: 运动中状态
- `Bit 5`: 系统急停

#### 4.3.3 RobotType (机型代码)
- `1`: CR3, `2`: CR5, `3`: CR10, `4`: CR16 ...
- `15`: CR3A, `16`: CR5A ...

## 5. 错误处理与故障排查 (Error Codes & Troubleshooting)

### 5.1 指令返回错误码 (ErrorID)

所有 Dashboard 指令都会返回一个 `ErrorID`，0 表示成功，负值表示不同类型的错误。

| 错误码 | 简述 | 详细描述 / 解决建议 |
| :--- | :--- | :--- |
| **-1** | 命令执行失败 | 已收到命令但执行逻辑失败（如抱闸控制时未下使能）。 |
| **-2** | 机器人报警中 | 需调用 `ClearError` 清除报警。 |
| **-3** | 机器人急停中 | 需松开急停按钮并清除报警。 |
| **-4** | 机械臂下电中 | 需先执行 `PowerOn`。 |
| **-5** | 脚本运行中 | 正在执行 Lua 脚本，部分指令被禁止。 |
| **-7** | 脚本暂停中 | 脚本处于暂停状态，需停止后才可切换。 |
| **-10000** | 命令不存在 | 检查拼写，Dashboard 不区分大小写。 |
| **-20000** | 参数数量错误 | 下发的参数个数与原型定义不符。 |
| **-3000X** | 必选参数类型错误 | 尾数 X 表示第几个参数。 |
| **-4000X** | 必选参数范围错误 | 参数数值超限。 |
| **-5000X** | 可选参数类型错误 | - |
| **-6000X** | 可选参数范围错误 | - |

### 5.2 参数命名格式要求
- 推荐使用 `key=value` 格式下发可选参数，提高代码可读性（如 `user=1, v=50`）。
- 若多个参数错误，系统仅返回检测到的第一个错误。
- 纯数字命名的工程名等字符串需加双引号。

## 7. 常见问题与示例 (FAQ & Examples)

### 7.1 典型开发流程示例

**1. 初始化与使能：**
```
RequestControl()        // 1. 请求控制权
PowerOn()               // 2. 机器人上电 (需等待约10s)
EnableRobot(1.5, 0, 0, 30) // 3. 使能并设置负载 (1.5kg, 偏移30mm)
```

**2. 简单运动控制：**
```
SpeedFactor(50)         // 设置全局速率 50%
MovJ(joint={0,0,90,0,90,0}, v=80) // 关节运动
MovL(pose={500,0,200,180,0,0}, speed=500) // 直线运动
```

**3. IO 与运动并发：**
```
// 当运动到 50% 距离时，自动开启 1 号数字输出
MovLIO(joint={10,10,10,0,0,0}, {0,50,1,1}) 
```

### 7.2 参数错误示例分析 (避坑指南)

- **错误示例 1**：`MovJ(joint="a", ...)` -> 返回 `-30001` (第一个必选参数类型错误)。
- **错误示例 2**：`DO(1, "2")` -> 返回 `-30002` (第二个必选参数类型错误，应为 int)。
- **错误示例 3**：`SetUser(1, {0,0,100,0,0,0}123, 1)` -> 返回 `-20000` (由于花括号后有冗余字符，参数数量解析错误)。

## 8. 全速开发支持

- **反馈获取**：强烈建议维持一个线程异步读取 30004 端口 (8ms 反馈)，以实时更新 UI 界面上的机器人位置、力矩及错误状态。
- **并发控制**：Dashboard 指令 (29999) 建议单线程顺序发送，或根据 ErrorID 确认上一条指令结束后再发送下一条（特别是立即指令）。
