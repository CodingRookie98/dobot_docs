## 设置LED灯的R、G、B值

- 
原型：

```python
magicbox.set_led_rgb(port, index, red, green, blue)

```

- 
描述：设置第 n 个灯的 R、G、B 值。

- 
必选参数：

  - port：控制盒端口。 数据类型：int，取值范围：1 ~ 6。

  - index：灯的位置。数据类型：int，取值范围：1 ~ 3。

  - red：红色的亮度数值。数据类型：int，取值范围：0 ~ 255。

  - green：绿色的亮度数值。数据类型：int，取值范围：0 ~ 255。

  - blue：蓝色的亮度数值。数据类型：int，取值范围：0 ~ 255。

- 返回：

  - True： 指令完成。

  - False： 指令未完成。

- 
示例

```python
magicbox.set_led_rgb(port=1, index=1, red=255, green=255, blue=255)

```

设置与控制盒Port 1连接的第1个编程灯的RGB值为(255, 255, 255)。

  - red：红色按钮状态。0：按下；1：弹起。

  - blue：蓝色按钮状态。0：按下；1：弹起。

- 
示例

```python
red,blue = magicbox.get_button_status(port=1)

```

获取与控制盒Port 1连接的双按钮模块的状态。

## 设置舵机角度

- 
原型：

```python
magicbox.set_servo_angle(port, angle)

```

- 
描述：设置舵机角度。

- 
必选参数：

  - port：控制盒端口。 数据类型：int，取值范围：1 ~ 6。

  - angle:角度。数据类型：float，取值范围：-180 ~ 180。

- 
返回：

  - True：设置成功。

  - False：未设置成功。

- 
示例

```python
magicbox.set_servo_angle(port=1, angle=90)

```

设置与控制盒port1连接的舵机角度为90°。
