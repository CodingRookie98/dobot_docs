## 人脸比对

- 
原型：

```python
face.match(image_a，image_b)

```

- 
描述：将两张图片中的人脸进行比对，返回比对结果。

- 
必选参数：

  - image_a：进行 BASE64转换后的图片。

  - image_b：进行 BASE64转换后的图片。

- 返回：

  - result：两张图片中人脸的相似度分数, 一般超过 80 分则可认定为同一人。

- 
示例

```python
image_a = xxx
image_b = xxx
result = face.match(image_a=image_a, image_b=image_b)
print(result)

```

将两张图片中的人脸进行比对，返回比对结果。

## 人脸检测与分析

- 
原型：

```python
face.detect(image, face_attributes, quality_detection)

```

- 
描述：对图片进行人脸检测与分析。

- 
必选参数： 

  - image：进行BASE64转换后的图片。

- 可选参数：

  - face_attributes：是否需要返回人脸属性信息。0 ：不需要返回；1 ：需要返回， 默认值为 0。

  - quality_detection：是否开启质量检测。0：关闭；1：开启，默认值为 0。

- 返回：result：图片人脸信息。

- 
示例        

```python
result = face.detect(image=image)
print(result)

```

对图片进行人脸检测与分析。

## 人脸搜索

- 
原型：

```python
face.search(group_ids, image)

```

- 
描述：在人员库列表中搜索目标人脸。

- 
必选参数：

  - group_ids：希望搜索的人员库列表。

  - image：进行 BASE64转换后的图片，base64 编码后大小不可超过 5M。

- 返回：

  - result：人脸搜索结果。

- 
示例        

```python
result = face.search(group_ids=group_ids, image=image)
print(result)

```

在人员库列表中搜索目标人脸。

## 创建人员库

- 
原型：

```python
face.create_library(group_name, group_id)

```

- 
描述：创建一个空的人员库。

- 
必选参数：

  - group_name：人员库名称，[1,60]个字符，可修改，不可重复。

  - groupid：人员库 ID，不可修改，不可重复。支持英文、数字、-%@#&，长 度限制 64B。

- 返回：

  - True： 指令完成。

  - False： 指令未完成。

- 
示例        

```python
result = face.create_library(group_name=group_name, group_id=group_id)
print(result)

```

创建一个空的人员库。

## 文本翻译

- 
原型：

```python
tmt.translation(source_text,source,target)

```

- 
描述：文本翻译。

- 
必选参数：

  - source_text：待翻译的文本，文本统一使用 utf-8 格式编码，非 utf-8 格式编码字符会翻译失败。

  - source：源语言，支持： auto：自动识别（识别为一种语言） zh：简体中文 zh TW：繁体中文 en：英语 ja：日语 ko：韩语 fr：法语 es：西班牙语 it：意 大利语 de：德语 tr：土耳其语 ru：俄语 pt：葡萄牙语 vi：越南语 id：印尼 语 th：泰语 ms：马来西亚语 ar：阿拉伯语 hi：印地语。

  - target：目标语言。

- 返回：

  - data：翻译后的内容。

- 
示例        

```python
text = "嘻嘻嘻嘻嘻"
result = tmt.translation(text, source="zh", target="en")
print(result)

```

将text文本内容从中文翻译为英文。

## 倒计时拍照

- 
原型：

```python
util.get_image(timeout, port, flip)

```

- 
描述：倒计时拍照及保存拍照文件。

- 
必选参数：

  - timeout：拍照延时时间，单位：秒。

  - port：相机端口。

  - flip：翻转图片, 默认不翻转。

- 返回：

  - image_data：拍照数据。

- 
示例        

```python
image_data = util.get_image(timeout=5, port=1, flip=False)
print(image_data)

```

利用相机端口1的相机进行拍照，设置拍照延时时间为5秒。
